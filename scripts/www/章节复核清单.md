# 章节归类复核清单

404 道题按 10 章归类，每题只归**一个主章节**，跨章题按「考察重点」归主章。
下表每章列 4 道典型题，供快速核对归类口径；完整标注见 `chap/p1.json`～`chap/p4.json`，
人工改判见 `chap/overrides.json`（理由在 `chap/overrides.why.json`）。

## 归类口径

- 有代码段、且代码只体现「赋值 → 输入 → 输出」的，归 2 顺序结构
- 出现 if / switch / 条件运算符，考点在分支的，归 3
- 出现 while / do-while / for / break / continue 的，归 4
- 讲函数定义、调用、参数传递、递归、局部变量的，归 5
- 讲 static / extern / register / auto、宏与 #include 的，归 6
- 讲数组定义、初始化、下标、字符串数组、数组作参数的，归 7
- 讲指针运算、指针与数组、指针作参数、函数指针、链表的，归 8
- 讲 struct / union / typedef / -> 与 . 访问的，归 9
- 讲 fopen / fprintf / fscanf / fgets / feof 与文件读写方式的，归 10
- 纯语法与语言规则（标识符、关键字、常量、运算符优先级、ASCII、注释、sizeof 是否为函数）归 1

## 各章典型题

### 1 基础知识（63 题）
- `1-1` 「任何表达式语句都是表达式加分号组成的。」→ 语句构成，属语法规则
- `1-84` 「在定义C语言的变量时，不能用关键字作为自定义的标识符」→ 标识符命名规则
- `1-229` 「字符串常量在内存中的存放位置由系统自动安排。」→ 常量与存储的概念题
- `1-12` 「float f=1234567890123.123456; printf("%f", f) 输出…第9位以后随机」→ 考 float 精度（数据类型基础），不因出现 printf 就归 2

### 2 顺序结构（22 题）
- `1-4` 「printf("%.2f",1.0/3); 输出为0.33。」→ 单条格式化输出 + 浮点除法
- `2-26` 「a=3，执行 a+=a-=a*a 后 a 的值是」→ 复合赋值求值（顺序执行），答案 -12
- `2-54` 「c1='A'、c2='D'，printf 输出…」→ 格式化输出字符变量的 ASCII 值
- `2-51` 「int x='f'; printf("%c",'A'+(x-'a'+1));」→ 字符运算 + 输出语句

### 3 选择结构（28 题）
- `1-20` 「if 三种形式中，满足条件要执行一组语句时必须用 {} 括起来」→ if 语法
- `1-45` 「break statement can be only used in loop body.」→ 考 break 与 switch 的关系（答案 F）
- `1-159` 「switch 语句中的 case 标签可以是任意字符串。」→ switch 标签类型
- `2-69` 「嵌套 if 时 C 规定 else 总是…」→ 悬空 else 配对规则

### 4 循环结构（75 题）
- `1-10` 「运行包含以下代码段的程序将可能进入死循环。」→ 循环终止条件
- `1-49` 「执行以下 while 语句将陷入死循环。」→ while 条件恒真
- `1-165` 「while 和 for 的执行次数没有限制，需要手动用 break 结束。」→ 循环控制（答案 F）
- `2-84` 「以下程序段的输出结果是」→ 嵌套循环打印乘法式

### 5 函数（36 题）
- `1-88` 「C 语言函数返回类型的默认定义类型是 void。」→ 函数返回类型默认值（答案 F，默认 int）
- `1-111` 「在函数内定义的变量称为局部变量。」→ 局部变量定义
- `1-184` 「用户自定义的函数在使用前必须加以说明。」→ 函数声明
- `1-201` 「递归并不节省存储器的开销…」→ 递归调用的栈开销

### 6 存储类型和预编译（16 题）
- `1-89` 「函数形参的存储单元是动态分配的。」→ 形参的存储类别
- `1-98` 「静态变量的作用域是整个文件。」→ static 的作用域（判断，答案 F）
- `1-189` 「局部变量存放在堆区，动态分配的内存位于栈区。」→ 存储区划分（答案 F）
- `2-143` 「在函数内定义变量时存储类型符可省略的是」→ 默认 auto

### 7 数组（59 题）
- `1-27` 「判断字符串 a 和 b 是否相等的表达式为 if(a==b)。」→ 字符数组比较（答案 F）
- `1-202` 「二维数组定义的一般形式…行长度和列长度都是整型常量表达式。」→ 数组维度定义
- `1-224` 「函数的参数可以是数组名，表示在函数中新建一个数组并完成值传递。」→ 数组作参数（答案 F，传地址）
- `2-105` 「以下能正确定义数组并正确赋初值的语句是」→ 数组初始化规则

### 8 指针（58 题）
- `1-100` 「可以用一个指针变量指向一个函数，然后通过该指针调用此函数。」→ 函数指针
- `1-228` 「int a[10],*p=a; p=a+1; 与 a=a+1; 都合法。」→ 数组名不可赋值（答案 F）
- `1-249` 「int a=2,*p1=&a,*p2=&a; (*p2)++; a=*p1**p2;」→ 多级解引用运算
- `2-141` 「基类型相同的两个指针变量，不能进行的运算是」→ 指针运算限制（答案 C）

### 9 结构体（24 题）
- `1-128` 「指向结构体变量的指针可以作函数参数，实现传址调用。」→ 结构体指针传参
- `1-255` 「结构体类型本身不占用内存空间，结构体变量占用内存空间。」→ 类型与变量
- `1-262` 「一个结构体类型中的各个成员类型必须相同。」→ 成员类型（答案 F）
- `2-136` 「p->str++ 中的 ++ 加在」→ -> 与 ++ 的优先级

### 10 文件（23 题）
- `1-135` 「文件指针和位置指针都是随着文件读写不断改变。」→ 两种指针的区别（答案 F）
- `1-140` 「一般不能用任何一个文本编辑器打开二进制文件进行阅读。」→ 文本/二进制文件
- `1-275` 「fgets 从当前文件位置指针开始读取字符，直到读到…」→ fgets 的结束条件
- `2-166` 「从 fp 所指文件读两个整数分别赋给 a、b 的正确形式是」→ fscanf 的调用形式

## 人工改判的 17 题

全部是「从 1 基础知识 移到 2 顺序结构」，理由统一：考的是 printf/scanf 的格式符与实参形式，
而不是语言规则本身。原归类把这类题都放进了「基础知识」，会让「顺序结构」只剩 5 题。

## 仍需留意的地方

- 「顺序结构」22 题偏少是**卷面本身如此**：全卷没有几道「整段程序只做赋值和输出」的题，
  其余求输出题都带分支或循环。章节练习里这一章会显得短。
- `1-12`（float 精度）、`2-125`（未定义行为）保留了 printf，但仍归 1，因为考点是类型精度与语言规则。
- 与关键词粗规则（`_dev/rules_ch.json`）冲突 120 余条，逐条核对过：粗规则只看关键词（出现 `char` 就归数组之类），
  冲突绝大多数是规则过粗，不是标注错误。
- 归不进任何章节的题：`2-146` 只剩「\*字符数组(1-3)」题干，已随解析一起从题库移除（进 `blocked.json`），
  所以选择页没有第 11 格。
